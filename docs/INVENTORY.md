# 文件整理范围

这个仓库整理的是可接续开发的当前源码、历史方法、已保存结果与模型入口；不是将原工作目录、私人素材和全部临时缓存原样上传。

| 原有内容 | 本次位置 / 处理 |
|---|---|
| 当前手机采集 App 与修复 | `apps/ios`；保留最新多传感器和独立音频开关；改为示例签名配置 |
| 找物 demo、自动分析、连接服务 | `apps/demo`、`services/bridge`；用虚构场景替换私人物品与媒体 |
| 最新 FHO 分阶段代码 | `training/fho/code`；保留流程顺序、依赖和结果说明 |
| 已保存分类头 / 部分微调模型 | 独立 `local-models` 包；`models/registry.json` 描述路径和哈希 |
| 较早训练/人工复核/teacher工具 | `training/historical`，明确标记历史入口 |
| 100DOH 手物模型源代码 | `baselines/hand_object`；大体积外部权重自行按说明获取 |
| 多传感器临时分析脚本 | 整理为 `tools/multisensor` 参数化审计/有声导出；不带硬编码私人路径 |
| 最新传感器对照 | `experiments/multisensor`，仅白名单聚合数字 |
| 全部旧输出 ZIP、构建目录、日志归档、重复快照 | 保留原机，不进入源码仓库；避免混用过时版本 |
| 家中影像、家人谈话、逐帧截图、真实物品记忆、原始传感器记录 | 不分享；静音版本依然是私人画面，也不纳入 |
| Ego4D 原视频/音频/抽帧、完整标注、候选标签表、缓存特征、逐例预测 | 不分享；成员使用自己的授权数据再生成 |
| 账号/密钥/登录态、Apple 团队、签名、设备标识、电脑个人路径 | 删除或替换成占位符；真实配置需成员本机填写 |
| 原 `.git` 历史 | 不带入；这是干净快照，避免历史中残留私密内容 |

## 不是“丢了”，而是没有保存的文件

某些旧实验保存了分数和汇总指标，但没有保存完整权重；本源码包仅收录聚合指标。具体清单见 [MODELS_MISSING_FILES.md](../training/fho/MODELS_MISSING_FILES.md)。本次没有用重新训练伪造旧 checkpoint，也不会将不匹配的模型标成某次最好结果。

下载的 ImageNet/100DOH/其他第三方预训练权重不作为本仓库源码分发。可用的自训头和部分已有 checkpoint 通过单独包共享，仍须遵守上游数据/模型条件。

## 溯源与完整性

模块内 README、验证记录和来源说明保留。包内 `MANIFEST.sha256` 列出源码快照的文件哈希；模型清单独立校验。源目录与原始实验文件均未因整理而改动。
