# Training and evaluation / 训练入口

当前主线在 [`fho/`](fho/README.md)：Ego4D FHO 人工标注产生弱标签，训练视频拿放代理分类器。最新保存的主模型是冻结 MobileNetV3-Small 加 10 帧时序 MLP，并不是大语言模型本身的微调，也没有完成眼镜端部署。

| 目录 | 用途 | 状态 |
|---|---|---|
| `fho/` | FHO 数据筛选、解码、10 帧特征、训练、评测、音频实验 | 当前可接续的实验代码 |
| `historical/` | 早期 4 帧人工/teacher 复核训练与十帧对照工具 | 历史参考，不能套用最新 AP |
| `../models/` | 权重登记、安装、校验、外部预训练下载 | 源码仓库不含权重二进制 |
| `../baselines/hand_object/` | 100DOH 手与物体接触检测 | 独立预训练基线，不识别拿放完成事件 |

先安装本地模型并运行 `fho/verify_models.py`，再决定是否复现实验。模型冒烟测试不需要数据集、GPU 或 API 账户。真实视频推理需要遵守原模型的抽帧及归一化规则。

新同学优先做：在获准使用的自有眼镜视频上标注拿放事件；用连续时间的召回、误触发次数、发给大模型的帧数和最终找物结果评估。已有 FHO AP 不能直接代表找物正确率、全天使用性能或手机功耗。

所有实验生成的图像、音频、特征、标签表、预测表和模型应留在 Git 忽略的本地目录中。数据集需由每位使用者按自己的访问协议取得。该仓库没有重发 Ego4D 数据的权限。
